### A branch that is still uncovered

`BookService.delete()` (lines 49–53) is red: neither `!repository.existsById(id)` = true (404) nor
= false (the actual delete) is executed by any test. It should be **tested, not deleted**: DELETE is
part of the public API, the 404 branch is the contract for a missing book, and the method carries
`@PreAuthorize("hasRole('ADMIN')")`, so a test would also prove that a USER cannot delete.

## Problem met during the work

`@WebMvcTest` first failed with `Mockito cannot mock this class: BookService` —
`Java 26 (70) is not supported by the current version of Byte Buddy which officially supports Java 24 (68)`.
IntelliJ was running the tests on JDK 26, while the project targets Java 21. Fix: project SDK,
run configurations and the Maven terminal (`JAVA_HOME`) switched to OpenJDK 21.0.2.
